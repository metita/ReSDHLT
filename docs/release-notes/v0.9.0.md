ReSDHLT 0.9.0 makes the complete compile pipeline faster, safer and easier to
operate from both the command line and the GUI.

## Highlights

- Corrected packaged settings dispatch, missing-value handling and BSP thread
  selection across CSG, BSP, VIS, RAD and RIPENT.
- Added portable and AVX2 build presets, isolated release outputs, strict
  warning enforcement, package smoke tests, symbols and SHA-256 manifests.
- Added RAD Sparse transfer acceleration, persistent Vulkan staging, direct
  gather acceleration, deterministic one-bounce GPU accumulation and a
  versioned CRC-checked lighting cache with safe CPU fallbacks.
- Added GUI preflight validation, immutable compile plans, proper dependency
  checks, cancellation, workspace locking, safe project persistence, complete
  GPU/BSP controls and accessible keyboard semantics.
- Hardened updates: explicit installation, portable-package selection,
  SHA-256 verification and detached Ed25519 signatures. The release signing
  seed remains only in GitHub Actions secrets.
- Added Clang C++17 portability fixes and regression coverage for the package,
  CLI argument validation, GUI behavior and updater verification.

The full technical history and benchmark notes are in
[CHANGELOG.md](https://github.com/metita/ReSDHLT/blob/main/CHANGELOG.md) and
[docs/BENCHMARKS.md](https://github.com/metita/ReSDHLT/blob/main/docs/BENCHMARKS.md).
