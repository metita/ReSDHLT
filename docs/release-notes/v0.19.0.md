ReSDHLT 0.19.0 lets every model on the map cast a shadow and stops a model from
going dark under its own shadow.

## Highlights

- New: `-studioshadowall` in RAD ("Sombras de todos los modelos" in the GUI).
  Every point entity with a `.mdl` model, `cycler_sprite` and the like, casts a
  shadow without `zhlt_studioshadow 1` on each one. Additive models and any
  other non-normal render mode under renderamt 255 are left out, and
  `zhlt_studioshadow 0` opts a single model out. It is off by default. RAD
  looks for the models in the folder above `maps`, so compile inside the game
  folder or the shadows are skipped.
- RAD: a model no longer goes dark from its own shadow. The game lights a whole
  model with one lightmap texel under it, and a model that shadowed that texel
  came out black. RAD now finds that texel the way the engine does and keeps it
  out of the model's own shadow. In a test room a tree right under a light read
  69 from its own shadow and now reads 159, against 160 for the same tree
  without shadows. The floor right under the model comes out a little lighter
  (5x5 texels, 3x3 with `-extra`). It is on by default and only touches models
  that cast shadows; "Dejar que el modelo tape su luz" in the GUI, or
  `-nostudiolightspot`, turns it off.
- RAD: a warning for every `.mdl` the game will draw black because there is no
  lightmap under it, saying when its origin is inside a solid.

Maps without shadow-casting models light the same as with 0.18.0. Checked on a
test map, not in the game yet: look at a map with models before you publish it.
