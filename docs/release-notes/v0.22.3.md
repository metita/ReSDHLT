ReSDHLT 0.22.3 fixes a crash in RAD on Linux. Windows builds were not affected,
and compiled maps come out the same `.bsp` as in 0.22.2.

## Fixed

- RAD: on Linux, a map with a studio model no longer crashes with a
  segmentation fault while the model's collision mesh is built. The tool read
  a field of the sequence group at the wrong offset on 64-bit and then used it
  to find the animation. It now uses the animation index alone, as the engine
  does for sequence group 0.
