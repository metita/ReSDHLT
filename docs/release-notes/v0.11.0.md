ReSDHLT 0.11.0 adds ray-traced ambient occlusion and makes the non-planar brush
fix cheaper in game.

## Highlights

- New: `-ao`, seedee's ray-traced ambient occlusion, with `-aoscale`, `-aogain`,
  `-aolevel`, `-aominweight`, `-aoopacity` and `-aocolor`. As upstream, it only
  darkens light gathered per sample (light, light_spot, light_environment), so a
  map lit by texlights barely changes.
- New: `-aoall` applies the same occlusion to all light, texlights and bounces
  included. This is the one to use on maps lit by texlights. On ze_elysium it
  darkened 27% of faces for about 4% more RAD time.
- With `-ao` or `-aoall` the direct-light gather runs on the CPU even with
  `-gpu`; transfers still use the GPU.
- Changed: non-planar brushes are only rebuilt when the mismatch is at least 0.2
  units. 0.10.3 rebuilt far more of them than needed and could add 17% to the
  faces the engine draws on a large map; now it is about 2%, and the seams it
  was meant to close stay closed. `-convexgap #` changes the threshold.
- Without `-ao` or `-aoall`, RAD writes the same file as 0.10.3.
