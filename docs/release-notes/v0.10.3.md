ReSDHLT 0.10.3 fixes maps that exceeded MAX_MAP_CLIPNODES with 0.10.2.

## Highlights

- Fixed: 0.10.2 rebuilds brushes with non-planar faces so the seams between
  them close, but the extra sides of those brushes also went into the clip
  hulls. A map near the clipnode limit that compiled with 0.10.0 could fail
  with 0.10.2 (one went from 32083 to over 32767 clipnodes). Collision now uses
  the brush as the .map writes it, exactly as before 0.10.2; only what is drawn
  uses the rebuilt shape, so the seams stay closed.
