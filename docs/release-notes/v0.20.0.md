ReSDHLT 0.20.0 reads the models for model shadows from the game, so a map
compiled outside the game folder keeps them, and stops counting player spawns
as models.

## Highlights

- RAD: the `.mdl` files for model shadows are also read from the game. After
  the folder above the map's, RAD looks in `-moddir <folder>` (for example
  `Half-Life/cstrike`), and without it in Counter-Strike in any Steam library
  it finds. In the game it reads `<mod>_addon`, `<mod>`, `<mod>_downloads` and
  `valve`, like the engine. The GUI passes `-moddir` from the game folder set
  for "Probar en el juego".
- RAD: player spawns and other `info_`, `light` and `path_` entities no longer
  count as models. Their `model` key (`gsg9.mdl` on the CS spawns) only tells
  the editor what to draw; with `-studioshadowall` they cast shadows of
  players that are not there.
- RAD: a missing model gives one warning with the number of entities using it,
  followed by the folders it was looked for in, instead of one warning per
  entity.
- RAD: a model path longer than 63 characters no longer overflows the model's
  name.

Maps without shadow-casting models light the same as with 0.19.0. Checked on a
test map compiled outside the game, not in the game yet.
