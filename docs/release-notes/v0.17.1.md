ReSDHLT 0.17.1 fixes maps with a dot in their name.

## Highlights

- Fixed: a map named like `pl_2.1.map` compiled through CSG and then BSP
  stopped with "BSP terminó con error" and nothing in `pl_2.1.log`. The tools
  took the `.1` for an extension and went looking for `pl_2.bsp`, writing the
  real error to `pl_2.log`. They now only strip `.map`, `.bsp` and `.ent`, and
  the GUI passes BSP, VIS and RAD the full `pl_2.1.bsp`, so the dot stays part
  of the name all the way through.
