ReSDHLT 0.22.0 gives the GUI an English interface. The compilers are the same
as in 0.21.0: the same map gives the same `.bsp`.

## Highlights

- GUI: every text is available in English and Spanish: the tabs, each option
  and its tooltip, the Guide tab, the Analysis findings, the compile and update
  messages. The GUI opens in the system language (Spanish on a Spanish system,
  English on any other) and the 🌐 button in the top bar pins either one. The
  choice is saved with the projects and applies at once.
- GUI: a new language is one `gui/lang/<code>.json` file and one line in
  `gui/src/i18n.rs`. `cargo test`, now part of CI, fails when a text has no
  translation, a translation has no text, or their placeholders differ.
