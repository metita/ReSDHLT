ReSDHLT 0.17.2 keeps RAD alive when the GPU driver crashes on start.

## Highlights

- Fixed: on some PCs RAD with the GPU on died right after the visibility
  matrix, with no error in the log and exit code -1073741819 (0xC0000005).
  The crash happened inside the Vulkan driver or an overlay layer while it
  started. RAD now starts Vulkan without the overlay layers, and if the driver
  still crashes it prints the reason and finishes the lighting on the CPU.
- The GUI shows the exit code of a stage that fails, so a crash no longer
  looks like a silent error.
- The `-texchop` warning only shows below 16, as it says.
