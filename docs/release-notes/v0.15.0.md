ReSDHLT 0.15.0 makes RAD much faster on maps with many lights, such as maps
lit by texlights.

## Highlights

- On ze_elysium_b1 (1,561 direct lights), with the GUI's settings, RAD went
  from 88.5 s to 49 s with the GPU on, and to 70.5 s on the CPU alone.
- New: `-vismatrix auto`. RAD uses the fast plain visibility matrix when it
  needs 512 MB or less, and the compressed one otherwise. On that map this
  phase went from 14 s to 3.4 s.
- The plain visibility matrix builds twice as fast.
- RAD no longer walks every leaf of the map for each light sample.
- On the CPU the .bsp is byte-identical to 0.14.0 on the five maps tested.
- GUI: Vismatrix now defaults to automatic and GPU acceleration defaults to on,
  with RAD choosing CPU or GPU for each phase. Without a Vulkan driver it
  falls back to the CPU. With the GPU, 0.6% of the lighting bytes change, by
  3/255 at most, which does not show. Projects saved with the old defaults
  move to the new ones once; values you changed by hand stay as they are.
