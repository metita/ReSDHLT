ReSDHLT 0.14.0 removes the world faces a func_wall hides completely, and fixes
two misleading results of the Análisis tab.

## Highlights

- New: "Poner NULL en caras tapadas" in the CSG tab (`-autonull`). World faces
  that a static func_wall covers entirely are set to NULL, as you would do by
  hand, without touching the editor. Only a func_wall nothing can change counts:
  no targetname, rendermode Normal, no zhlt_invisible or zhlt_noclip, and only
  opaque textures. A face is removed only when one of its brushes covers the
  whole face. Off by default: without it the map compiles exactly as in 0.13.0.
- Fixed: the Análisis tab no longer treats a func_illusionary as covering what
  is behind it. It is not solid, so a player can walk into a bush and see the
  floor under it; putting NULL there would show the void.
- Fixed: a spot a static func_wall covers is no longer reported as a hole, and
  hole rays no longer start inside one.
