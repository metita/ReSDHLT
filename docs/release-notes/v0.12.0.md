ReSDHLT 0.12.0 adds two opt-in lighting options and two scripts that show where
a map loses frame rate or lightmap space.

## Highlights

- New: `-pcf N` softens shadow edges. Every sample traces N x N shadow rays per
  light instead of one, so the edge becomes a short gradient instead of a
  staircase of texels. `-pcf 3` is the useful setting. It covers light,
  light_spot and light_environment, and runs the direct-light gather on the CPU
  even with `-gpu`; transfers still use the GPU.
- New: `-blurclamp N` (0 to 1) keeps bright subsamples from bleeding into dark
  ones when RAD smooths each lightmap texel: thin shadows and the foot of walls
  stay dark. 0.5 is a good start.
- Neither option touches fast texlights, which RAD adds at patch level. On a map
  lit almost only by them, like ze_elysium, they barely change anything.
- New script: `scripts/wpolymap.py map.bsp --pts out.pts` counts the world faces
  each spot sends to the renderer (what `wpoly` and FPS follow) and marks the
  worst areas as a pointfile you load in J.A.C.K. like a leak trail.
- New script: `scripts/hiddenfaces.py map.bsp` lists faces drawn for nothing:
  world faces fully hidden behind a func_wall or func_illusionary, and entity
  faces buried inside world brushes. Put NULL on them or use func_detail.
- Without `-pcf` or `-blurclamp`, RAD writes the same file as 0.11.0. CSG, BSP
  and VIS did not change.
