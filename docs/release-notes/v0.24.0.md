ReSDHLT 0.24.0 delivers a major speedup to `sdHLRAD` for complex maps, especially
outdoor maps with spread sunlight, `-softsky`, `-aoall` and `-studioshadowall`.

On a real-world benchmark map (`zpl_ragnaros_sulfuron_b2`, 11,791 faces, 53,311
patches, 28 studio models, `-extra -aoall -studioshadowall -bounce 12 -skylevel 6
-softsky 1`), RAD compile time dropped from ~20 minutes to **1m 50s** on a
GTX 1060 3GB.

## Highlights

- **RAD (GPU Studio Model Shadows):** studio models (`.mdl`) are now raytraced
  directly on the GPU using a flat per-model binary BVH, Möller-Trumbore
  intersection, and 1-bit alpha masks for `STUDIO_NF_TRANSPARENT` textures.
  `-studioshadow` and `-studioshadowall` no longer force the CPU gather path.
- **RAD (GPU Ambient Occlusion):** added a dedicated Vulkan compute shader
  (`ao.comp`) for `-aoall` and unlocked GPU gather when `-aoall` is active.
- **RAD (Deep BSP GPU Gather):** added `d96`, `d128`, `d192` and single-style
  `s1_d32` Vulkan gather pipelines; deep BSP trees run the compact `d32` fast
  path first and only re-dispatch samples that overflow the stack.
- **RAD (Adaptive Sun Cone & Coarse-to-Fine Sky Dome):** 13-probe sun-cone
  early-out for spread `light_environment` entities, 2-level coarse-to-fine
  `-softsky` tracing (both CPU and GPU), and automatic merging of identical
  `light_environment` entities.
- **RAD (GPU VisLeafs):** `BuildVisLeafs` (both normal and sparse vismatrix)
  now batches BSP visibility rays on the GPU.
- **RAD (`-gpuauto` & `-extraadapt`):** `-gpuauto` now counts sun-spread rays
  when deciding between CPU and GPU; added opt-in `-extraadapt [threshold]` for
  adaptive `-extra` supersampling.
