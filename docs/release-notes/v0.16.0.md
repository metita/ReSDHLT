ReSDHLT 0.16.0 makes RAD with the GPU a third faster again.

## Highlights

- On ze_elysium_b1 with the GUI's settings, RAD went from 52 s in 0.15.0 to
  34 s, with the same .bsp as 0.15.0's GPU output.
- The GPU and the CPU now work at the same time: while the GPU lights one
  batch of faces, the CPU prepares the next one and finishes the previous.
- The texlight pairs the GPU hands back to the CPU are resolved on all cores;
  before, they ran on one thread and hid inside the GPU's time.
- Automatic Vismatrix picks sparse when the GPU is on, since the GPU only
  computes transfer factors for that matrix.
- BuildVisLeafs no longer scans every face of the map for each leaf.
- On the CPU alone the .bsp is byte for byte the one 0.14.0 wrote.
