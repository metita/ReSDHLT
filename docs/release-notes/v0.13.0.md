ReSDHLT 0.13.0 puts everything in the GUI: every option this fork adds has a
control, and the compiled map gets checked without Python.

## Highlights

- New in the CSG tab, "Brushes deformados": the fix for brushes bent with vertex
  manipulation and the gap that triggers it (`-noconvexfix`, `-convexgap`).
- New in the RAD tab, "Sombras y oclusión": ambient occlusion (`-ao` or
  `-aoall`, with scale, opacity, falloff, rays and color), soft shadows (`-pcf`)
  and `-blurclamp`. All off by default: without touching them the map compiles
  exactly as before.
- New "Análisis" tab. After every successful compile it checks the `.bsp` by
  itself: see-through holes, the areas that draw the most wpoly, faces hidden
  behind a func_wall or func_illusionary or buried in walls, and broken
  geometry. Each finding has a coordinate to copy, and each list saves as a
  pointfile you open in J.A.C.K. with Map > Load Pointfile, like a leak trail.
- The Python scripts stay in the repo for command-line use; the GUI gives the
  same results.
- The compile tools themselves did not change: same output as 0.12.0.
